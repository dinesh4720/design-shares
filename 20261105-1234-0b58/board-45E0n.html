Final Verdict

No. Charts should use one set of colours that stays the same whichever brand colour is picked. Only light and dark mode get their own versions, and each reader picks solid or gradient fills. The brand colour is for buttons and menus, not for data.

1

Charts use the eight colours in order, and a category keeps the same colour on every chart.

2

Warning, error and success keep their own colours, which are never used for ordinary data.

3

Steps in a process, like Draft to Approved, use shades of one fixed colour, not of the brand colour.

4

Charts with one set of data use the first colour; labels mean no one relies on colour alone.

5

Solid or gradient is set in the Theme menu and applies to every chart. A gradient only lightens the same colour, so it never changes what a colour means.
